Trained Models, Running in Your Browser

These are the projects' own trained models, not re-creations. They download only when you press Run, then run on this page; nothing you draw or show them leaves your device.

Shape Classifier

A small CNN that names the shape in a 64 x 64 image (circle, square, triangle, rectangle, pentagon, hexagon or star) and draws a box around it. It scored 99.20% on 2,000 held-out images.

  1. Pick a test shape below, or switch to Draw your own.
  2. Press Run the model. The first run downloads it (about 3 MB).
  3. Read the scores for all 7 shapes, and the box the model drew.
Input

Draw one filled shape with your finger or mouse. Your drawing is not like the training images (those are clean, filled and slightly noisy), so expect lower accuracy here; the 99.20% applies only to the test shapes.

Pentagons and hexagons, highlighted, are the pair it confuses most: at 64 x 64 pixels their corners blur into near-circles.

The model and test images come from Solid Object Detection: the same ONNX file it serves on AWS Lambda, and 9 images of each shape from its seed-42 held-out split (FINDINGS). For a test shape, the page also shows Python's score for the same image; every deploy checks the two agree.
