Data Contract & Quality Checker

Before a new file of job postings is used, check it against rules learned from a file you trust: no missing values, no duplicate IDs, salaries in a normal range, known categories only.

  1. Leave "Monday's file" as the good example the rules are learned from.
  2. Pick a day's file to check (Tuesday and Wednesday have problems hidden in them).
  3. Press Check the file and see which rules broke, and on which rows.

A file you choose is read on this page and never uploaded. Up to 5 MB.

The Job Market Lakehouse runs rules like these with Great Expectations after every PySpark job. A failed check stops the pipeline before bad data reaches a report.
